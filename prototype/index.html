演示动线（约 8 分钟）

按这条线走一遍，能把「采集 → 编码 → 检索 → 研判 → 预警 → 处置」讲完

  1. 1

    入口与身份

    从 登录页 进入，用演示账号切换两端。要讲的点：两端共用一套设计语言，只在信息密度上区分。

  2. 2

    个人端：一次完整筛查

    我的首页 → 量表作答（一屏一题）。要讲的点：第 9 题问自伤念头，答「好几天」时不自动翻页，把支持资源留在眼前。

  3. 3

    个人端：多模态采集

    采集工作台，切三个页签。要讲的点：三类信号进同一套编码空间，这是后续跨模态检索的前提。

  4. 4

    核心：跨模态检索 + RAG

    检索与分析 → RAG 结果。要讲的点：一段文字也能命中语音与图像单元；报告分「结论 / 依据 / 建议」，并说明依据来自哪几条命中。

  5. 5

    闭环：预警与处置

    个人预警中心 → 管理端概览 → 预警管理。要讲的点：同一事件在两端口径一致，管理端能看到未分配、处理人与处置完成度。

  6. 6

    把 AI 关进笼子

    预警研判台。要讲的点：四项权限闸门（是否允许诊断、是否允许自动干预）由后端下发；任务只出草案，必须人工确认；接口未接通时按钮直接禁用，不伪造成功态。

动线里每一步都能点开；页面之间也用侧栏互相可达，不需要记地址。

怎么用这份原型

不需要起服务、不需要构建，直接用浏览器打开 HTML

模式
  • 右上角按钮切换浅色 / 深色，选择记在本机
  • 地址栏加 #light / #dark 可强制指定
状态直达
  • #safety 量表安全题 / #result 结果态
  • #image 采集图像页签 · #audio 审阅语音页签
截图与说明
  • screenshots/ 内有 2x 截图与命名规则
  • DEMO.md 是这份动线的文字版
原型与线上代码解耦：prototype/ 不参与任何构建，也不影响 frontend/ 的运行。字段、阈值与文案均可在仓库源码中对应到出处。
