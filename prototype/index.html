怎么用这份原型

不需要起服务、不需要构建，直接用浏览器打开 HTML 即可

模式
  • 顶栏右侧按钮切换浅色 / 深色，选择记在 localStorage
  • URL 加 #light / #dark 可强制指定
状态直达
  • #safety / #result 量表两个关键状态
  • #image 采集页的图像模态
截图
  • 见 screenshots/，2x 分辨率，命名规则写在同目录 README
原型与线上代码解耦：prototype/ 不参与任何构建，也不影响 frontend/ 的运行。

心理筛查预警系统 · 前端高保真原型 · 内容与阈值取自仓库真实实现（questionnaireData.ts / mockData.ts / alert_rules）
