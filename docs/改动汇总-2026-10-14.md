## 一、个人端首页（`pages/Dashboard.tsx`）

### 1. 三栏重排 + 压扁

原来的检测结果卡是"四段竖排、横跨整页"，右侧空一大片。改成**内部三栏**：

```
量表给的分数  │  最近一次输入 + 检索结果  │  RAG 给出的解释与建议
```

高度从 ≈550px 压到与下面那一排卡片齐平。

### 2.「最近一次输入」的取值链

| 情况 | 显示 |
|---|---|
| 首次引导刚提交的补充 | 优先用它 |
| 否则最近一条**带 supplement** 的记录 | 注意不是 `records[0]`（它可能没补充，而第 3 条有） |
| 文本 | **原文照展** |
| 语音 / 图像 | 按语料里的写法描述特征，**不展示原始文件** |
| 都没有 | 后端语料样例（`corpus.db` 的 `R0001-txt`）+「**样例**」标记 |

「样例」标记的口径：**只要展示的不是用户自己写的原文就标**，避免把语料当成用户输入。

### 3. 接真检索

有文本输入 → `POST /api/personal/search`，拿该输入对应的：

- **相似记录**（前两条，带模态标签 + 相似度）
- **RAG 解释与建议**（`report.summary` + `recommendations` + `riskLevel`）

三态标记如实区分：**`实时` / `演示` / `未跑成`**。标记跟着 `USE_MOCK` 与后端返回走，mock 模式下**不会**冒充实时。

> 中途踩过一次：标记最初只判断"请求有没有 resolve"，mock 分支也会 resolve，于是把演示数据标成了「实时」。已修。

### 4. 版式细节

- 三个栏目标题统一 **15px / 600 / `slate-700`**（原 13px/400，和辅助说明同一档，不像标题）
- 表头**钉在顶部对齐**，只把下面的分数+分数带在剩余高度里**竖直居中**
- 问候语改用**登录用户名**（原来用 `userProfile.name`，演示数据里是"林晓"，和右上角的 `xiaoyu` 打架）

### 5. 修掉「永远骨架屏」

加载失败与加载中原来是**同一个分支**：凭证过期时页面会「提示 + 骨架屏」永久挂着不动。现在拆开：

- 加载中 → 骨架屏（会自己结束）
- **加载失败 → 失败卡 + 具体原因 + 「重新登录」按钮**

## 二、检索与分析（`pages/Retrieval.tsx`）

1. **空状态换成 300 条语料库历史记录**（原是一张图标 + 一句话），点一条直接填进检索框
2. **三种模态分类**：全部 / 文本 / 语音 / 图像 —— 切换时**展示该模态的单元内容**
   - 文本 → 自述原文
   - 语音 → 「语音片段特征：句中被叹气声打断…」
   - 图像 → 「记录到的非言语线索：人物被画得很小，缩在纸的一角…」
   - ⚠️ 第三路是**图像**不是视频（`units.modality` 只有 `text/audio/image`，`video` 为 0）
3. **「返回历史记录」入口**，与「RAG智能分析」并排、同一款式 —— 检索后历史列表会被结果区顶掉，必须有路回去
4. **并入自己采集的记录**：列表 = `[...mine, ...corpusRecords]`，行结构完全一致
5. 删掉「还有 N 条 →」（占一行且没必要）

**以案为中心**，不是以功能为中心。左栏待处置队列，右栏同一个案子的四段：

```
① 结论（先行）    建议 48 小时内面谈
```

## 五、共享层

### `components/AppShell.tsx`

- **分组名上移到顶栏**：顶栏第二段从「页名」改成「分组名」（工作空间 / 智能分析 / 健康管理…）
- **去掉页头眉标**：原来写「个人端 · 工作空间」，和顶栏的「个人端 │ …」重复；分组名上移后眉标即可删掉

### `services/http.ts` —— 401 分级

原来**任何业务接口的 401 都会 `clearToken()` + 跳登录**，一个可选增强接口的鉴权失败能毁掉整个会话。现在先拿一个**核心接口复验**：

- 复验也 401 → 凭证确实失效 → 照旧清凭证 + 跳登录
- 复验通过 → 是这个接口自己的问题 → 只透传错误

> 说明：这是**预防性加固**，不是修 bug。实测本后端在有效 token 下业务接口回的是 403 而非 401，所以当前不会触发。

### `pages/first/FirstRunSupplement.tsx`

删除「提交前预览」整块（含它专用的 `hasContent` 变量）。

### `data/corpusRecords.ts`（新增）

从 `backend/data/hashing/corpus.db` 导出：**300 条记录 × 3 模态**（171 KB）。每条含 `text / audio / image` 三个字段，另带主题、等级、日期、情境。
