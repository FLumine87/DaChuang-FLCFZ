# 改动：登录不再落到首次引导页 + 笔记本矮屏适配

日期：2026-11-07

## 背景

核验时反馈两件事：

1. 每次登录都会进到一个「很奇怪的界面」——那是 `/personal/welcome`（首次引导欢迎页），
   无侧栏、整屏分屏布局，和正常工作台完全不同；
2. 那个界面（以及主页）在笔记本屏幕上「和屏幕对不上、没展示全」。

## 一、登录落点改为工作台

`frontend/src/auth/entryPath.ts`

- 个人用户登录后一律进 `/personal/dashboard`（个人首页/工作台），管理员进 `/admin/dashboard`。
- 不再根据 localStorage 里的引导状态跳欢迎页。原判据的硬伤：
  - 换浏览器 / 无痕 / 清站点数据 = 状态丢失 → **每次登录都再拦一次**；
  - 那一页是整屏分屏，笔记本上常常装不下（见下）。
- `/personal/welcome` 与三步首次引导 `/personal/first/*` **保留**，只是不再由登录自动触发；
  首页的「记录一下现在 / 评估心理状态」和心理筛查页的「量表填写」标签仍可开始首次筛查。

## 二、主页首屏矮屏适配

`frontend/src/index.css`、`frontend/src/pages/LandingPage.tsx`

- 13–16 寸笔记本（浏览器工具栏占位后可视高度常只有 700–820px）里，首屏原本按 900+ 设计，
  「立即体验」下面的两个立项标签被推到屏幕外，看起来像被切掉。
- 新增 `@media (max-height: 820px)` / `(max-height: 740px)` 两档，只收紧首屏 `#top`：
  标题 52 → 40 → 34px，正文 18 → 16 → 15px、行高收一档，纵向留白压缩。
- 实测 1270×750、1152×720、1280×700 下 CTA 与两个标签都在首屏内。

## 三、个人首页在 1024–1439 宽度下的错位

`frontend/src/pages/Dashboard.tsx`、`frontend/src/index.css`

- 原布局在 1024–1439 保持「左标题 + 右 430px 计划卡」：内容区（扣掉 290px 侧栏）只剩
  670–1090px，左栏被挤到 500px 以内，54px 标题折行、`lg:whitespace-nowrap`
  的副标题直接**压到右侧「今日行动计划」卡片上**（1270×750 实测）。
- 修法：
  - 1180px 以下改单列（计划卡排到标题下面）；1180–1535 右栏 380px；2xl 恢复 430px；
  - 标题字号 1024–1439 为 44px，1440 以上才 54px；
  - 去掉副标题的 `whitespace-nowrap`，改为正常换行。
- 实测 1270×750、1024×768 均单行标题、无重叠。

## 四、侧栏在矮屏下挤掉导航

`frontend/src/components/AppShell.tsx`、`frontend/src/index.css`

- 侧栏底部那张装饰卡（"每一份关注，都有意义"）在 ≤820px 高度时会把「健康管理」整组挤出可视区，
  看起来像菜单少了一项。这一档直接隐藏该卡，把高度让给导航。
