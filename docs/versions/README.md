# 静态镜像页版本留存

这里保存各阶段的**单文件静态镜像页**（`frontend/public/login.html` 的快照）。
它不依赖构建工具，双击即可在浏览器打开，用于演示、答辩与评审沟通。

> ⚠️ 仓库 `.gitignore` 有全局 `*.png` 规则，但 HTML 不受影响，本目录会被 git 跟踪。

## 版本对照

| 文件 | 阶段 | 内容 |
| --- | --- | --- |
| `心理筛查预警-一改-1012版.html` | 一改（10-12） | 登录页初版：只有登录页，顶栏的章节导航是装饰性的（点击不能翻页），对应提交 `caa1879` |
| `心理筛查预警-二改-1013版.html` | 二改（10-13） | 主页 5 屏（作品简介 + 核心技术 + 状态评估 + 预警处置 + 隐私安全）+ 独立登录页，含动态背景、整屏翻页与逐级入场动画 |

## 与 React 版的关系

- **源文件**：`frontend/public/login.html`，由 React 版同步而来（不是独立维护的第二套代码）
- **同步方式**：`bash scripts/sync-html-to-desktop.sh`（会把最新版放到桌面，并重建一改版）
- **一致性核验**（浏览器读计算样式对比 React 与 HTML，2026-10-13）：

  | 项目 | React | HTML |
  | --- | --- | --- |
  | 抗锯齿 | `auto`（系统次像素） | 一致 |
  | 字体栈 | `-apple-system` 打头 | 一致 |
  | 大标题 | 68px / 500 / 0.25px | 一致 |
  | 正文 | 400 / `rgb(71,84,103)` | 一致 |
  | 顶栏 | 透明底 + `blur(14px) saturate(1.8)` | 一致 |
  | 导航 | 16px / 内距 20px | 一致 |
  | 动态背景 | 5 组极光 + 15 片玻璃 | 一致 |

  已知差异（结构性，非缺陷）：镜像页是**单文件六屏**（含登录屏），React 版已拆成
  `/`（主页 5 屏）与 `/login` 两个路由。
