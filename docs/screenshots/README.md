## 命名与整理规则

- 原文件来自桌面 `截屏YYYY-MM-DD HH.MM.SS.png`，归档时重命名为
  `YYYYMMDD-HHMMSS-内容描述.png`，**保留原时间戳**以便按时间回溯。
- 按内容分子目录（如 `01-系统界面走查`、`02-开发过程留痕`），每个批次根目录放一份 `索引.md`，
  记录画面要点、关联提交与「未纳入 / 移出」的文件及原因。
- 与本项目无关的截图不放进来：课程学习类进 `~/课程截图/`，个人内容（游戏、账号、消费记录）留在桌面。

## 注意

仓库 `.gitignore` 有全局 `*.png` 规则，因此**截图文件不被 git 跟踪**，只有各批次 `索引.md` 会入库。
若希望截图随仓库提交，需要在 `.gitignore` 中追加例外，例如：

```
!docs/screenshots/**/*.png
```
