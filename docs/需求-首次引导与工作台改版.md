## 二、量表介绍弹窗（图六）

- 顶部英文 `ABOUT THE QUESTIONNAIRE` 改为小字「量表介绍」，主标题改为「PHQ-9 抑郁症状自评量表」
- 标题下方一句话说明；主体改成「这份量表关注什么」，四组简短内容，每组左侧一枚**同尺寸浅蓝线性图标**
- **删除**弹窗里的「怎么作答」「结果如何使用」，以及占据较大面积的「需要提前知道」卡片
- 阅读顺序：**名称 → 用途 → 关注的状态**，不做成操作教程
- 后续追加：**关闭入口只留一个**（右上角 ×；另有 Esc 与点背景兜底）；**背景不要虚化**（整页糊成色块很难受）

落点：`pages/first/ScaleIntroDialog.tsx`

## 三、答题页（图六）

1. 卡片顶栏：左「PHQ-9 情绪筛查」，右依次「ⓘ 了解 PHQ-9」「第 2 / 9 题」，介绍入口始终可点
2. 进度条下、题目上方：一条**低对比度说明栏**（左：小日历图标 + 回想的时间范围；右：单选圆点图标 + 按什么选一项）
3. 题目下原有"在过去两周里……"与说明栏重复，删去
4. 选项下、翻页按钮上方：一行小号文字 + 信息图标说明结果用途，普通提示样式，不做成警告卡
5. **第 9 题单独处理**：该题选项旁给紧凑的「需要支持时」支持卡，进入第 9 题时就可见；具体求助方式在卡内展开
6. 视觉层级：**题目和四个选项最突出 > 进度 > 说明文字**

后续追加（你逐条提的）：

- 题目**不要断在词中间**，填满一行再换行（禁用 balance/pretty）
- **答题卡从始至终保持一样大**，不为长题目加宽
- 选完自动翻页；**回车**也能到下一题；页脚不要写额外说明
- **答满即可提交**，不要让用户一路点「下一题」挪到最后一题
- 漏答提示**只在最后一题**出现，且只列"别的"漏题，题号可点跳回

落点：`pages/first/FirstRunQuestionnaire.tsx`

## 四、四份量表的介绍文案（图七）

每份按「简介 / 它关注什么 / 它如何帮助你 / 结果的边界」四段写，四份齐全（PHQ-9、GAD-7、ISI、PSS-10）。

特别要求：**PSS-10 不用于诊断、没有统一分界值**，平台显示的「低、中、高」必须写成**系统参考分组**，不能写成临床结论。

落点：`data/scaleGuide.ts`

## 五、02 补充记录 / 03 本次结果

**02（图二）**

- 左侧：标题 + 一句说明 + **步骤条**（不要再把技术介绍独立摆在左下角）
- 两段技术说明移到**右侧输入区下面**，合成一条「报告生成方式」：动态跨模态哈希检索 → RAG 检索增强生成，浅蓝灰小字 + 小图标 + 淡边框，宽度与输入框对齐、高度约 64–80px；技术名称直接可见，解释点 (i) 再展开
- 顺序固定：标题说明 → 文字/语音/图像切换 → 输入区 → 技术说明 → 提交/跳过
- 步骤统一成四步：`选择方向 → 回答问题 → 补充记录（可选） → 查看结果`，顶部进度同步（`n/4`），状态字**靠近步骤名称**

**03（图三~五）**

- 右侧合成**一张「本次筛查报告卡」**：顶部（本次筛查结果 + 量表名/完成时间）→ 核心结果（得分，切标签时始终可见）→ 三个标签（结果摘要 / 分析依据 / 后续建议）→ 底部按钮
- 左侧约占 35%，右侧报告约占 65%；左栏与右卡**顶部对齐**；标题改「了解当下，接下来有方向。」
- 结果摘要：一段解释 + 必要说明，不重复得分、首次不画趋势
- 分析依据：可展开条目（本次作答与补充 / 动态跨模态哈希检索 / RAG 参考资料），尚未接通的两项要**明确标注尚未参与本次结果**
- 后续建议：两三条，短标题 + 一句说明 + 相关操作
- 「查看完整分析」改名为**「查看本次记录」**；后又确认**底部该按钮去掉**
- PSS-10 的分数**不做临床分级**：不写"中度压力"、不配四色风险条，只写「本次压力感受记录 + 得分 + 量表范围 0–40」+ 一条 0–40 刻度
- 后续追加：结果摘要里**结论与免责声明要拉开层级**（结论更突出）

落点：`pages/first/FirstRunSupplement.tsx`、`pages/first/FirstRunResult.tsx`
