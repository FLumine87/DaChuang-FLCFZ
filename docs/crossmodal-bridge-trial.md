# 跨模态桥接本地试合并

本地试验分支：`trial/crossmodal-bridge-20261109`。从 main 的
`921a0d1` 合入 `feature/zwz-crossmodal-bridge` 的 `6dbec4a`，保留 main
原有采集页、报告模板和本次输入隔离机制。前端没有改动。

## 兼容修正

- 检索前初始化主索引，已初始化时不重复加载。桥接单元统一映射为主索引的编号，
  并使用主索引当前的权限、标签来源、摘要和媒体信息。
- 图像查询的“全部模态”保留文本、语音、图像单元；不会因为来源记录相同而互相覆盖。
- 桥接探测使用二进制哈希码，连续向量仅用于非对称评分。校验真实特征维度，
  避免把特征维度和哈希码长度混淆；缺失模型和无命中时回退主引擎。
- CNN 图像特征在建库和查询中保持一致；切换图像编码器或训练模态时拒绝旧模型。
- 运行时图像同步桥接时重新抽取 CNN 特征，避免把手工图像特征送入 CNN 投影。
- 构建脚本支持显式只读语料路径、图像模型路径和独立输出目录；采样后抽取特征，
  保留每个模态自己的编号和标签来源。音搜图仍使用主引擎。

## 本地验证与限制

- 新增 10 项桥接兼容测试，覆盖权限过滤、编号映射、三模态结果、筛查引用、模型缺失回退、
  编码维度和持久化重载。完整后端 107 项测试通过，结果见本地 `.trial-data/backend-tests.log`。
- 前端 TypeScript 检查与 Vite 生产构建通过。
- 只读使用现有真实语料，各抽取 80 组配对分别训练文图和音图小模型。
  重载后文搜图、图搜文、音搜图、图搜音均可返回结果，并转换为筛查引用。
  结果记录在本地 `.trial-data/real-smoke.json`。
- 使用隔离的主索引快照验证实际 `perform_search` 入口：文搜图合并、图搜文桥接、
  图搜音桥接和图像全部模态四条路径通过，并可构造筛查引用。
  结果记录在 `.trial-data/endpoint-smoke.json`，未调用外部大模型。
- 小模型及主索引快照只存放于忽略目录 `.trial-data/`。这不是完整规模的上线模型，
  本次验证没有独立测试集准确率结论。分支已有离线指标不能当成本次线上路由的提升证明。
- 情绪弱配对仍然存在；命中其他模态不能证明用户本人多模态一致，也不能直接代表疾病诊断。

原主工作区、原始数据库未因试验被修改；本次不推送远端。
