## 发现并解决的问题

1. 普通数据库读取方法不提交 `UPDATE ... RETURNING`：改为专用原子写入方法，并用独立数据库连接验证落盘。
2. 同秒内多次运行可能取错最新记录：报告保存时间改为微秒精度。
3. 编码后的案例和任务 ID：接口显式解码，并增加路由测试。
4. Windows PowerShell 5.1 对无 BOM 的中文脚本读取失败：修复合成语音生成脚本编码。
5. 个案运行时按钮失焦，Esc 关闭失效：补充抽屉层的键盘处理并通过浏览器回归。
6. 院系列表不应只从当前报告派生：改为由当前数据空间返回完整院系选项。
7. 静态素材地址适配前端部署基础路径。
8. 首个浏览器及打包 Chromium 启动超时：改用已安装的 Edge 完成验证。
