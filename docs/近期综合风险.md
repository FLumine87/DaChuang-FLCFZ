# 统一近期综合风险

当前状态由主业务后端 `risk_summary` 唯一计算。个人心理档案、首页原有检测结果区域、预警页、管理端档案和工作台读取同一结果；历史筛查和预警仍保留发生时的结论。首页首屏及知识图谱布局不变。

## 指标和规则

- 范围：上海时区近30个自然日，覆盖全部有效本人筛查。量表分别计分，采用同量表最新有效结果；同版本、不同日期结果提供分数变化，不跨量表平均。
- PHQ-9/GAD-7/ISI采用已有统一计分规则；安全条目单独处理。PSS-10只显示连续分数与变化，不凭总分生成黄色或诊断等级。版本或答案不兼容的记录保留历史并注明资料缺口。
- 本人文字、语音转写中的明确困扰、持续频繁表达和生活影响按统一规则处理。图像/语音文件的存在、文件名、自动特征描述不能证明心理状态。检索黄色参考只能请求关注，不能直接生成橙红等级或证明本人症状；积极匹配不能证明整体低风险。
- 近14天3个不同日期的本人负面记录触发工程人工复核关注规则，配置沿用 `SCREENING_NEGATIVE_WINDOW_DAYS` 和 `SCREENING_NEGATIVE_DAY_THRESHOLD`。同日重复记录只计一次，积极记录不抵消独立安全线索。该规则未作临床效度验证。
- 等级统一为：待评估、现有记录未提示明显关注信号、需要关注、建议人工复核、需及时安全复核。用于筛查关注和支持优先级，不是诊断或自伤概率。资料不足不自动变绿。
- 未复核的历史安全提示独立保留，过期记录不让当前等级永久为红色。普通预警“已缓解”和计划完成不解除安全提示。关联补充继承同一量表安全条目时不重复生成提示。

## AI和授权

在“设置”底部“心理管家与记忆设置”开启“允许AI提取筛查线索用于近期综合评估”。此项默认关闭；同时要求心理管家和筛查来源开启。基础规则汇总始终可用，不要求开启AI。沿用既有 LongCat 等已配置模型，不新增模型密钥。

后台每15秒调度，最多两个账号并行；每批最多4段原文，长记录按4000字分段并重叠200字。后续批次继续覆盖全部近期记录，不使用前65条等截断。以来源内容、模型和提示版本缓存，模型失败标记失败并约5分钟后重试。页面显示完整处理进度及失败状态。

AI只能提取症状相关表达、持续时间、频率、生活影响、安全疑似线索，必须逐字引用本人原文、标明明确或不确定。服务端校验账号、授权、日期、来源内容版本和原文。未经人工核实的AI推测不直接改变等级；人工确认的生活影响/安全线索最多触发橙色复核，不能由AI直接生成红色等级。

关闭授权或清空记忆时同步撤回并清除提取缓存，迟到任务不会采用；同步失联超过5分钟时AI授权失效，基础规则继续工作。每日问询、私人聊天、MBTI和任务完成情况均不作为本轮综合风险输入。陪伴聊天和RAG只引用统一等级，不另定当前风险。

## 接口和复核

- `GET /api/personal/risk-summary`：本人摘要，独立于心理管家开关。
- `GET /api/admin/cases/{case_code}/risk-summary`：管理端相同摘要，增加授权管理端可见的复核记录。没有唯一账号关联时返回409，不按姓名合并。
- `POST /api/admin/cases/{case_code}/risk-reviews`：管理端人工复核，提交 `item_id`、`source_hash`、`action`、`note`。操作为 `resolve_safety`、`followup_safety`、`confirm_finding`、`dismiss_finding`；必须填写复核意见，记录操作账号、时间和来源版本。原文改变后旧复核不能套用。
- `GET /api/admin/risk-summary`：按稳定账号去重的当前人数分布，与历史预警事件数量分别展示。
- `/api/internal/steward/risk-summary`、`risk-context`、`risk-consent`、`risk-extraction`：仅接受现有HMAC服务签名；浏览器JWT不能用于内部写入。

摘要包括统一等级、规则和数据版本、日期窗口、四个量表维度、原因与来源、独立安全提示、数据覆盖/兼容缺口、AI处理状态及全部纳入记录。读取重新计算，因此新增、修改、删除和自然日跨窗会自动反映；界面每30秒刷新，不在GET中调用大模型。

新表为 `risk_ai_consent`、`risk_extractions`、`risk_reviews`，启动时增量建立。没有改写历史分数、风险颜色或原始记录；所有日期窗口和归属检查都在服务端完成。双目录继续各用自己的数据库、端口及同步签名密钥。
