# 改动：工作台（个人端 / 管理端）对齐登录页视觉

> 缘起：2026-10-13「将用户端和管理员端的风格和登录页面端改的差不多一致，你先做一版」。
> 本文档记录这一版做了什么、令牌取值从哪来、验证到什么程度，以及留给「二改」的部分。
>
> 范围：**只动工作台外壳（AppShell）与共享令牌**，不动登录页、主页、静态镜像页，
> 也不动各页面的业务结构与文案。

## 一、改造前的差距

登录页/主页（参考基准）与工作台原本是两套语言：

| 维度 | 登录页 · 主页 | 工作台（原） |
| --- | --- | --- |
| 页面底色 | `bg-page`（#f7f9fe） | `bg-slate-50`（#f9fafb），另一个灰 |
| 背景纹理 | 细网格 + 同心圆轨道 / 极光 | 无，纯色 |
| 顶栏 | `nav-blur` 透明毛玻璃、64px、无下边框 | 白底 + 1px 下边框、82px |
| 侧栏 | —（无侧栏） | 不透明白板 |
| 卡片 | `rounded-3xl`（24px）+ 大范围柔和投影 | `rounded-2xl`→1rem（16px）、无投影 |
| 页面标题 | 眉标（13px / 字距 .16em / 主色）+ 标题 + 说明 | 只有 h1 + 说明，无眉标 |
| 控件 | 按钮/输入框 `rounded-xl`、高 44~48px | 按钮 `rounded-lg`（8px）、高 42px |
| 图标按钮 | 无底框 36px 方块，悬停浮出淡底 | 白底描边 42px |

## 二、这一版做了什么

### 1. 共享令牌（`src/index.css`）

新增 `:root` 令牌，值全部取自登录页，避免两处各写一份魔法数字：

```css
--card-radius: 1.5rem;                                  /* = 登录页卡片 rounded-3xl */
--card-shadow: 0 20px 50px -32px rgba(16,24,40,.22);    /* 登录页是 0 24px 70px -36px /.35，见下 */
--control-radius: 0.75rem;                              /* = 登录页按钮/输入框 rounded-xl */
```

> 投影没有照搬登录页的 `.35`：登录页一屏只有一张卡，工作台一屏十几张，
> 原样叠加会糊成一片灰，因此收敛到 `.22` 并把范围收窄一档。深色下几乎不可见，
> 另给一条更深的变量保持"浮起"感。

落到既有组件类上（`ui-card` 全项目用了 81 处，改一处全站生效）：

| 类 | 改动 |
| --- | --- |
| `.ui-card` | 1rem → `--card-radius`，并加上 `--card-shadow` |
| `.ui-button` | 圆角 0.5rem → `--control-radius`，最小高度 42 → 44px |
| `.ui-icon-button` | 白底描边 42px → 无底框 38px 圆角方块（悬停才浮出淡底）；全项目仅 3 处引用 |
| `.ui-table th` | 加 `letter-spacing: .06em`，与登录页眉标同向 |
| `.app-content` | `max-width` 1600 → **1440px**（= 登录页/主页的 `max-w-[1440px]`），内距 28 → 32px |
| `.sidebar-link` | 圆角 0.5rem → `--control-radius`，悬停改为半透明白 |
| `.app-sidebar` | 白底 → `color-mix(white 76%, transparent)` + `blur(18px) saturate(180%)` |

**新增的标题层级**（写在 `@layer` 之外，否则压不过已有的 `h1 { 26px }` 未分层规则）：

```css
.app-page-eyebrow { font-size: .8125rem; letter-spacing: .16em; color: primary-500 }
.app-page-title   { font-size: 1.875rem; font-weight: 500; letter-spacing: .25px }
```

即登录页卡片的「眉标 → 标题 → 说明」三段式。标题取 30px 而不是主页那档 38~68px：
工作台一屏要放数据，展示型大标题会把内容挤下去。

### 2. 背景层

- 工作台根节点 `bg-slate-50` → **`bg-page`**，与登录页/主页同一个底色变量（深色自动翻转）。
- 新增 `.app-ambient` 固定层，里面放两样东西：
  - `Aurora`（极光，原在 `pages/introSections.tsx`，为复用上移到 `components/Aurora.tsx`，
    由 `introSections` 原样再导出，主页引用未改）；
  - `.app-grid` 细网格纹理——**复用了登录页那层网格**：它原先挂在 `.auth-shell::before` 上，
    但全项目没有任何组件用过 `.auth-shell`，是拆登录页时留下的死代码，这次原地接管
    （连同深色变体一起改名），没有再复制一遍同样的渐变。
- 在工作台里对极光做了两处克制：
  - 光斑 `opacity: .6`（登录页是"近白底 + 极淡纹理"，原样铺满会让工作台整体泛蓝）；
  - 隐藏那三片 40~58vw 的 `.glass`：它们在主页是整屏背景的一部分，放进工作台就是压在
    表格后面的浅蓝大方块（还能看到硬边），喧宾夺主。

### 3. 应用外壳（`src/components/AppShell.tsx`）

个人端与管理端共用这一个外壳（`Layout.tsx` / `AdminLayout.tsx` 只传 `mode`），所以两端同时生效。

- 顶栏：白底 82px + 下边框 → **`nav-blur` 透明毛玻璃 64px**，左侧补上「个人端/管理端 ｜ 当前页名」
  （与登录页顶栏「健康管理平台 ｜ 登录」同一做法）；搜索框改为 `h-10` 半透明胶囊。
- 主题切换按钮：改用登录页/主页顶栏那一颗（无底框 36px 圆角方块、图标悬停旋转），
  三处顶栏至此完全一致。
- 页面头：新增眉标一行（`个人端 · 工作空间`），标题换成 `.app-page-title`；
  面包屑只在二级页出现（首页原本会显示「个人首页 > 个人首页」，同一句话说两遍）。
- 侧栏：品牌行 96 → **64px**，与顶栏等高、底边对齐；底部说明卡改为淡玻璃 + 边框。
- 内容区：每次换页重放 260ms 的 `.page-enter` 淡入上浮，与登录页 ↔ 主页的转场同一段动画。
- 手机抽屉：`@media (max-width: 1023px)` 里把侧栏**改回不透明**——抽屉是盖在深色遮罩上的，
  半透明玻璃会透出遮罩、整体发灰且对比度下降。另补了 `@supports not (backdrop-filter)` 兜底。

## 四、留给「二改」

1. **各页面内部的灰色块**：页面里还有 49 处 `bg-slate-50` 的小底块（筛选条、内嵌面板）。
   现在页面底色变浅、卡片加投影后，这些块的白/灰关系值得再统一一轮。
2. **输入框/按钮尺寸**：登录页输入框是 `h-12`，工作台里多数是 `h-10~11`。
   是否要拉到同一个高度档，取决于你更看重"完全一致"还是工作台的信息密度。
3. **静态镜像页**：`frontend/public/login.html` 只有主页 5 屏 + 登录屏，**不含工作台**，
   因此本次没有需要同步的内容（`scripts/sync-html-to-desktop.sh` 无需执行）。
4. 若更想靠近主页那种"有动感"的观感，把 `.app-ambient .aurora span` 的 `opacity`
   调回 1、并放开 `.glass` 即可（两处都在 `index.css` 的 `.app-ambient` 段内）。
