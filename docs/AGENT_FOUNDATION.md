# Agent 第 0 步 证据包与安全边界

## 已完成

- 所有 Agent 输入统一为 `build_evidence_pack()` 输出的匿名化证据包。
- 证据包只包含量表、预警等级、趋势和相似模式聚合结果；不会包含姓名、联系方式、原始作答、自由文本、文件路径或命中案例原文。
- 高风险预警（橙色、红色）固定标记为必须人工复核，Agent 不具备诊断、降级或自动结案权限。

## 需要完成的事

1. 与指导老师和学校确认知情同意文本、数据保存期限、人工复核人和高风险升级流程。
2. 在创建筛查的页面增加明确的同意选项；只有真实完成该流程的记录才能由授权后台将同意状态更新为 `approved`。
3. 为连续随访在内部服务中绑定同一对象的筛查记录。不能用姓名、电话或院系匹配。
4. 生产环境使用随机长密钥生成稳定匿名标识，并仅以 Secret 形式保存。
