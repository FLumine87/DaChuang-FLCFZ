# Agent 第 0 步 证据包与安全边界

## 已完成（用户端 RAG 证据包）

- `build_evidence_pack()` 输出的匿名化证据包只包含量表、预警等级、趋势和相似模式聚合结果；不会包含姓名、联系方式、原始作答、自由文本、文件路径或命中案例原文。
- 高风险预警（橙色、红色）固定标记为必须人工复核，Agent 不具备诊断、降级或自动结案权限。

## 管理端 AI 研判（个案 + 群体）

管理端「预警研判与处置」使用 `app/services/agent_ai.py` 构造独立于用户端 RAG 的证据包：

- 个案输入：问卷历史（最多 5 条）、当前等级/分数、趋势、多模态材料摘要（最多 6 条）。
- 群体输入：窗口/院系范围、预警分布、趋势计数、院系聚合（人数 < 3 折叠为「其他」）、匿名主体（最多 60 条）。
- 发送前移除姓名、电话、证件号、邮箱、案例编号、筛查编号与文件名；自由文本做手机号/证件号/邮箱/超长数字掩码。
- 多模态只发送文本内容、描述与检索结论摘要，不发送原始音频/图片，也不据此推断情绪或心理状态。
- 模型输出只做依据概述、发现结论与建议；不改变预警等级、不自动创建任务、不自动干预。
- 总开关：账号设置 → 智能研判模型（存库 `agent_model_settings`）；调用参数见 `AGENT_AI_TIMEOUT_SECONDS` / `AGENT_AI_MAX_SUBJECTS` / `AGENT_AI_MIN_DEPT_SIZE` / `AGENT_AI_MAX_MATERIALS`。
- 状态：`generated` / `disabled` / `not_configured` / `unavailable`；任何失败都降级为规则结果，不影响研判主流程。
- 审计：`agent_model_calls` 只记录 scope、主体引用、用途、状态、模型、耗时与错误类型，不保存 prompt/response 原文。

`AGENT_ALLOW_EXTERNAL_LLM` 仍只约束用户端 RAG 报告；管理端研判以账号设置里的模型开关为准。

## 需要完成的事

1. 与指导老师和学校确认知情同意文本、数据保存期限、人工复核人和高风险升级流程。
2. 在创建筛查的页面增加明确的同意选项；只有真实完成该流程的记录才能由授权后台将同意状态更新为 `approved`。
3. 为连续随访在内部服务中绑定同一对象的筛查记录。不能用姓名、电话或院系匹配。
4. 生产环境使用随机长密钥生成稳定匿名标识，并仅以 Secret 形式保存。
