# 方案：主页与登录页拆分

> 缘起：2026-10-13 老师反馈「主页是主页，登录是登录」——参照腾讯官网，
> 进入后先是介绍公司的主页，要登录时点「登录」按钮再跳转到登录界面。
> 本文档只给方案，未改动前端代码。

## 一、老师意见的落点

| 老师的话 | 我的理解 | 当前状态 |
| --- | --- | --- |
| 「主页是主页，登录是登录」 | 主页与登录页必须是**两个独立页面**，不能把登录表单放进介绍流的第一屏 | ❌ 现在是同一页的第 1 屏 |
| 「你进去之后是主页，主页就是介绍这家公司」 | 进入站点先看到**作品/产品介绍**，不需要登录 | ❌ 现在进去先看到登录表单 |
| 「要登录的时候才点击登录按钮，跳转到登录界面」 | 主页上有一个**显式的登录入口**，点击后进入独立登录页 | ❌ 现在没有独立的登录入口 |

腾讯官网核对：`www.tencent.com` 顶栏是「关于我们 / 我们的创新 / 我们的行动 / 投资者」等纯内容板块，
主页只做介绍；登录在另一个入口（id.qq.com 等）。**与老师给的模型一致。**

## 二、目标结构

```
/            主页（作品介绍）· 公开，无需登录
             ├ 顶栏：Logo │ 作品简介 核心技术 状态评估 预警处置 隐私安全 │ [登录系统] [主题]
             ├ 首屏：徽章 + 大标题 + 正文 + 三条要点 + 评估链路卡 + [登录系统] [了解技术路线]
             ├ 第 2~5 屏：核心技术 / 状态评估 / 预警处置 / 隐私安全（保留整屏翻页）
             └ 滑动引导、页码点、滚动高亮

/login       登录页 · 独立页，居中卡片
             ├ 品牌标识 + 一句话
             ├ 登录卡：欢迎回来 → 登录 / 注册 → 用户名 / 密码 → [登录并进入系统]
             ├ 演示账号一键填充（评委会用）
             ├ 管理员登录切换
             └ 「← 返回主页」

/personal/*  个人端（需登录）
/admin/*     管理端（需登录）
```

**路由与跳转**

| 场景 | 行为 |
| --- | --- |
| 访问 `/` | 显示主页（已登录与否都显示，主页是公开的） |
| 点顶栏「登录系统」或首屏 CTA | → `/login` |
| 登录成功 | 按角色 → `/personal/dashboard` 或 `/admin/dashboard` |
| 未登录访问受保护页 | → `/login?redirect=<原地址>`，登录后回到原页 |
| **已登录**访问 `/login` | 直接重定向到对应工作台（避免重复登录） |
| 已登录访问 `/` | 顶栏按钮文案变「进入系统」，点击直接进工作台 |
| 访问旧地址 `/auth` | 重定向到 `/login`（评委可能存了旧链接） |

## 四、两个关键取舍（想听你的意见）

**① 登录页要不要保留左侧宣传文案？**

| 方案 | 优点 | 缺点 |
| --- | --- | --- |
| **A. 极简居中**（推荐） | 与老师模型一致：介绍在主页做完了，登录页专注登录；快、干净 | 页面上信息少，略朴素 |
| B. 保留左栏文案 | 视觉丰富，与现在的首页接近 | 与主页首屏内容重复，回到「一页两职」的老问题 |

**② 主页首屏用什么内容？**

现在首屏是登录表单，拆开后首屏空出来了。我建议**直接把「作品简介」提到第一屏**：

```
● 心理筛查与健康管理平台  ·  国家级大创立项 · 2026-06  ·  金种子重点课题
多模态心理筛查与分级预警系统            ← 60px 大标题
以动态跨模态哈希检索为核心……            ← 20px 正文
✓ 三条要点
[登录系统]  [了解技术路线]              ← CTA
                        右侧：评估链路卡（四节点折线图）
```

理由：这套内容本来就是这个项目对外讲清楚「是什么、怎么做」的最强一屏，做主页首屏最合适；
四章节顺势后移为第 2~5 屏。
