# 管理端四项改进与验收说明

按《管理端.docx》四项建议，在主分支 ec75988 上续做。第一项截图实际是首页「最新预警」表，因此入口跳转到对应预警详情。Agent 工作台由队友负责，本次没有改动。

| 建议 | 改动 | 验收方式 |
| --- | --- | --- |
| 首页记录可打开 | 最新预警姓名旁增加「查看详情」，URL 保存预警编号 | 点击、刷新、返回均能找到对应预警 |
| 筛查管理包含多模态 | 增加「多模态采集与分析」页签，读取个人端实际保存的数据 | 文本、语音、图像、独立采集/关联筛查、已有分析和关联预警；支持搜索、模态筛选及分页 |
| 预警入口更明显 | 保留空态引导，卡片增加「查看详情与处置」和无障碍名称 | 鼠标/键盘可打开；重复点同一条不再卡在加载状态 |
| 图像和语音查询异常 | 纯媒体可提交；音频转为 PCM WAV；校验文件、显示读取和失败状态、防重复提交；新增录音和取消 | 无文字图片查询、失败重试、取消录音、录音转 WAV 查询 |

## 数据与接口

新增管理员接口 GET /api/admin/supplements，参数 keyword、kind、page，返回 items、total、page、pageSize，每页 50 条。读取个人端已经保存的 screening_supplements，通过 user_id 关联姓名；保留未关联问卷的独立采集，不按姓名猜测归属。

列表不返回上传文件 URL；详情展示已有文字、说明、文件名和分析结论，没有分析时明确提示。没有新增风险推断或自动处置。现有数据库具备 screening_supplements 表即可使用，无新增迁移。普通用户访问返回 403。演示模式显示空态并标记，不捏造采集记录。

检索沿用 POST /api/admin/search 和现有引擎。音频在浏览器解码为 24414Hz 单声道 16bit WAV；浏览器不支持的格式会提示错误。录音沿用项目已有 useAudioRecorder（最长 60 秒）。上传与转换后文件均限 8MB。图片支持 PNG/JPG/BMP/WebP，损坏图片拒绝提交。

- backend：python scripts/test_admin_workflow.py，8 项通过。新增用例覆盖实际多模态记录读取、筛选、独立采集、权限及不返回上传 URL。

浏览器回归使用真实 React 页面、受控模拟接口及浏览器假麦克风：覆盖首页直达/刷新/返回、多模态详情及关联预警、纯图片提交/503 重试/防连点、录音取消/转 WAV 查询。这不代表真麦克风、真实检索质量或生产部署已验证。后端测试用临时数据库，不修改团队演示库。

重跑浏览器测试前，在 frontend 用 VITE_USE_MOCK=false、VITE_API_BASE_URL 为空启动：npm run dev -- --host 127.0.0.1 --port 5176 --strictPort。再在另一窗口执行上述 Playwright 命令。

## 队长合并后演示

启动项目、登录管理端，从首页点最新预警，刷新应保留详情。切换到筛查管理的多模态页，与个人端已保存记录比对，查看分析并打开关联预警。最后到检索页，选择图片、不写文字直接检索，再测试录音、停止使用和取消。
