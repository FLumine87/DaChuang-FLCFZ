# 首次筛查 · 评委体验界面稿

本组为静态设计方案。对应流程：逐题作答 → 可选补充 → 查看结果与依据。
沿用原有深蓝背景、蓝紫按钮、双栏布局；以技术名称加一句用途的方式展示项目创新。

## 展示安排

- 作答页：左下“报告形成方式”展示动态跨模态哈希检索与 RAG；右侧保留题目、单选项、量表介绍、进度和翻页。
- 第 9 题特殊状态：技术说明让位于支持信息卡；提醒与支持方式在选择前可见。继续沿用既有第 9 题设计方向，本组三张图展示的是第 2 题。
- 可选补充页：技术说明与文字、语音、图像入口对应；保留直接跳过。
- 结果页：当前展示“分析依据”标签页。新增结构化报告、知识关联入口、后续记录提示和专业评估提示。结果为明确标注的示例。
- 参考申报书第 6、9 页的跨模态检索、RAG、知识图谱与跟踪思路；不将持续记录误称为个人模型自动学习，不添加未经验证的精度、性能或隐私保证。
- 正式实现时只展示本次实际采用的线索与资料；技术流程说明不是后台实时运行状态。
