# 新版界面整合（2026-10-11）

最新设计源为 `prototype/`，实际登录与业务路由仍由 `frontend/` React 应用承载。此次迁入暖灰配色、字体、紧凑导航/卡片/表格、个人首页与管理员图表布局；保留原有筛查、详情入口、预警、档案和 API 接口，不用原型的静态数字替换业务数据。

同时同步原型的交互修正：问卷退出/重置确认、图片删除入口常显、报告风险来自返回字段。尚未接入保存接口的情绪日记及智能体确认操作明确禁用，不再提示虚假的保存成功。

## 本地预览与登录

在 `frontend` 目录运行 `npm run dev:demo`，打开 http://127.0.0.1:5173/ 。此模式使用演示数据，不需要后端。

- 个人用户：`xiaoyu` / `123456`
- 管理员：`adminer` / `admin`

`npm run dev` 保留原有环境配置，连接真实后端时需要后端服务、数据库及对应账户可用。演示模式登录成功不代表真实后端联调完成。

后续应直接修改 `frontend/` 才会更新登录后的应用；`prototype/` 作为设计参考保留，并非应用入口。此次为共享视觉规范与主要页面迁移，不代表全部静态原型逐像素复刻。
